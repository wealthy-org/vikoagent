- (decision) Responsive behavior stacks dashboard panels on narrow viewports; no critical state relies on hover, color alone, or animation.
- (decision) UX scope is responsive web dashboard for internal developers; desktop-first with narrow viewport support.
- (decision) UX prioritizes inspectability: every decision shows action, reason, timestamp, token reference, and linked receipt where applicable.
- (decision) Primary information architecture is Header/Health, Scanner, Mind Stream, Treasury, Receipts, and System State.
- (decision) Visual language adopts Vikoagent obsidian surfaces, violet accents, glass panels, purple eye orb, Sora/Inter/JetBrains Mono roles, and explicit Devnet/Paper labels from brief.
